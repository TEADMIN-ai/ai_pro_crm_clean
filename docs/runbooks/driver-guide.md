# Driver Guide

## Driver Scope

Drivers should be routed to hygiene jobs and should not see admin, QS, contractor list, or vehicle finance management surfaces.

## QA Workflow

1. Log in as driver.
2. Open assigned hygiene job.
3. Review job details and service steps.
4. Capture evidence/signature only in approved QA/staging flows.
5. Confirm completion state is clear.

## Support Notes

If a driver cannot see a job, check assigned user IDs, job status, and role claim.
