# Contractor Runbook

## Daily Tasks

- Check onboarding email or manual link from Torque Empire.
- Create password using the secure onboarding link.
- Log in to the contractor portal.
- Upload required compliance documents.
- Monitor document review feedback and re-upload rejected documents.

## Workflow Diagram

```text
Receive invitation
  -> Open onboarding link
  -> Create password
  -> Log in
  -> Upload compliance documents
  -> Accept onboarding acknowledgement
  -> Wait for staff review
  -> Re-upload any rejected/expired documents
```

## Troubleshooting

Invitation email not received:

- Check spam/junk folder.
- Ask the Torque Empire manager or admin for the manual onboarding link.

Onboarding link expired:

- Request a new onboarding/password reset link.

Cannot log in:

- Confirm password setup was completed.
- Confirm the email address matches the invited contractor email.
- Ask staff to verify contractor account status.

Document rejected:

- Upload a clearer/current document.
- Check expiry dates and company details before re-upload.

## Escalation Paths

- Login or password issue: Torque Empire manager/admin.
- Missing document guidance: assigned staff member.
- Urgent tender deadline issue: manager.
- Suspected account compromise: admin immediately.
