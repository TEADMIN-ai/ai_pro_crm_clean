# Supplier Intelligence Guide

## Supported Workflows

- Supplier profile review.
- Supplier offers.
- Supplier performance ratings.
- Preferred/watchlist/blocked decision flags.
- Regional and transport intelligence foundations where data exists.

## QA Checks

- Confirm supplier scores are explainable.
- Confirm blocked supplier warning affects recommendation UI.
- Confirm sponsored/preferred status does not override true scoring.
- Confirm insufficient regional/price-history data is labelled clearly.
