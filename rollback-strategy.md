# EmpirePDF Rollback Strategy

Generated: 2026-05-31

## Rollback Goal

Allow EmpirePDF tender-pack activation to be disabled quickly without changing route URLs, breaking the existing UI button, or deleting the simple-pack generator.

## Preferred Rollback Mechanism

Use a server-side feature flag:

- `EMPIREPDF_TENDER_PACK_ENABLED=false`

When false:

- `/api/tender-pack/generate` uses the current `generateSimplePack(...)` path.
- `templateKey` remains or returns to `"simple"`.
- UI behavior remains compatible with the current response shape.

When true:

- `/api/tender-pack/generate` uses `generateMergedPack(...)`.
- `templateKey` becomes `"summary-sbd1-sbd4"` or equivalent.

## Template Rollback

Before promoting candidate templates:

1. Create a backup of:
   - `public/templates/SBD1.pdf`
   - `public/templates/SBD4.pdf`
2. Record file sizes and checksums.
3. Store backups outside the deployment overwrite path.

Rollback steps:

1. Disable `EMPIREPDF_TENDER_PACK_ENABLED`.
2. Restore the previous `public/templates/SBD1.pdf` and `public/templates/SBD4.pdf` if they were replaced.
3. Redeploy or restart only if the runtime caches template files.
4. Generate a pack through the UI and confirm `templateKey: simple` in persisted metadata.

## Route Rollback

No route rename is recommended. Rollback should not require changing UI code if `/api/tender-pack/generate` keeps the same request and response contract.

If feature flag fails:

1. Revert only `src/app/api/tender-pack/generate/route.ts` to call `generateSimplePack(...)`.
2. Leave `generateMergedPack(...)`, `fillSbd1(...)`, and `fillSbd4(...)` intact.
3. Leave `/api/tender-pack` and `/api/tender-pack/preview-pdf` intact because they already use the merged path separately.

## Data Rollback

Generated PDFs are persisted as immutable artifacts under `tenderPacks/{contractorId}/...`.

Rollback does not need to delete already generated EmpirePDF packs unless there is a data/privacy issue. Instead:

- Use `templateKey` to identify whether a pack was generated by `simple` or `summary-sbd1-sbd4`.
- Preserve `warnings` and `fieldMapUsed` for audit.
- If a generated artifact is invalid, mark or supersede it with a new generated pack rather than mutating the stored PDF.

## Monitoring During Activation

Watch:

- `tenderPacks.templateKey`
- PDF file size changes
- `warnings` array
- generation errors from `/api/tender-pack/generate`
- fallback warnings from EmpirePDF
- user reports that download URL opens the wrong document

Expected activation signal:

- New generated packs have a merged-pack template key.
- File size is materially different from simple one-page PDFs.
- Downloaded package contains summary + SBD1 + SBD4.

## Rollback Triggers

Rollback immediately if:

- `/api/tender-pack/generate` returns 500 errors for ready contractors.
- Signed download URLs are missing or invalid.
- Generated packs are simple text PDFs when the feature flag is on.
- SBD1 or SBD4 pages are missing from the package.
- SBD1 signature suppression regresses.
- Active calibrated fields use fallback placement in final output.
- Candidate PDFs are discovered to be filled acceptance outputs rather than clean runtime templates.

## Estimated Rollback Time

Feature flag rollback: minutes.

Template file rollback: 10 to 30 minutes, depending on deployment process and cache behavior.

Code rollback without feature flag: one focused route revert plus deployment.

## Rollback Risks

- If candidate PDFs replace `public/templates` without backups, rollback depends on git history or deployment artifact recovery.
- If UI response shape changes during activation, rollback may require UI changes as well.
- If `generateSimplePack` is deleted or modified instead of left intact, rollback becomes slower and riskier.
- If persisted `templateKey` is not changed for EmpirePDF packs, it will be harder to distinguish old and new generated artifacts.

## Recommended Safe Activation Pattern

1. Preserve `generateSimplePack(...)` unchanged.
2. Keep `/api/tender-pack/generate` route name unchanged.
3. Use `EMPIREPDF_TENDER_PACK_ENABLED` to choose the generator internally.
4. Keep response JSON backward compatible.
5. Back up active templates before promotion.
6. Use distinct `templateKey` metadata for EmpirePDF output.
7. Disable the flag for immediate rollback.
